# BON in a Box MCCP Data server

A [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) server that provides access to the BON in a BOX pipeline engine through natural language queries.

```bash
pip install -r requirements.txt
python server.py
```

### Resources

- `bon://list` - List all available scripts and pipelines
- `bon://scripts` - Get list of available scripts
- `bon://pipelines` - Get list of available pipelines

### Prompts

- `bon-in-a-box-mcp`
